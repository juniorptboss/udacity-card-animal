# Cartão de Animal — Wolf

Projeto de estudo de **HTML e CSS**, desenvolvido no contexto dos exercícios da Udacity.

A página apresenta um cartão sobre um lobo, com imagem, uma lista de características e texto descritivo. O exercício reúne a estruturação do conteúdo em HTML e a estilização do cartão em um arquivo CSS separado.

## Conteúdo do cartão

O cartão contém o título **Wolf**, uma imagem local, uma frase de destaque, uma lista de características e um parágrafo descritivo.

## Tecnologias e conceitos

**HTML** para organizar títulos, parágrafos, imagem e lista. **CSS** para definir dimensões, espaçamentos, bordas, sombra e tipografia.

O código utiliza seletores por elemento, identificador e classe, além de `box-sizing`, `padding`, `margin`, `border` e `box-shadow`.

## Como visualizar localmente

Baixe o repositório como ZIP e extraia os arquivos, ou utilize o Git:

```sh
git clone https://github.com/juniorptboss/udacity-card-animal.git
cd udacity-card-animal
```

Abra o arquivo **`card.html`** no navegador. Mantenha `styles.css` e `wolf.png` na mesma pasta para preservar o carregamento dos estilos e da imagem.

Não há etapa de compilação ou instalação de pacotes. Os estilos e a imagem utilizados pela página estão incluídos no repositório.

## Estrutura

```text
udacity-card-animal/
├── README.MD    # Apresentação e instruções do exercício
├── card.html    # Estrutura e conteúdo do cartão
├── styles.css   # Estilos do cartão
└── wolf.png     # Imagem utilizada na página
```

## Contexto educacional

Este repositório registra a prática de fundamentos de front-end por meio da construção de um cartão informativo, com foco na separação entre conteúdo e apresentação.
